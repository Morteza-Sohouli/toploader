# تاپلودر - رابط کاربری

رابط کاربری مدرن و زیبا برای سرویس اشتراک‌گذاری فایل تاپلودر

## ویژگی‌ها

✨ **طراحی مدرن و زیبا** با Tailwind CSS  
🌙 **پشتیبانی از حالت تاریک و روشن** با تشخیص خودکار تم سیستم  
🇮🇷 **طراحی فارسی** با فونت وزیرمتن و پشتیبانی کامل از RTL  
📱 **کاملاً ریسپانسیو** برای تمام دستگاه‌ها  
🚀 **تجربه کاربری عالی** با انیمیشن‌های روان و رابط کاربری بصری  
📤 **آپلود فایل با نوار پیشرفت** و پشتیبانی از drag & drop  
🔒 **امنیت بالا** با مدیریت احراز هویت جلسه‌ای  
⚡ **سرعت بالا** با Vue 3 و Vite

## نصب و راه‌اندازی

### پیش‌نیازها

- Node.js (نسخه 18 یا بالاتر)
- npm یا yarn

### مراحل نصب

1. نصب وابستگی‌ها:

```bash
npm install
```

2. اجرای سرور توسعه:

```bash
npm run dev
```

3. ساخت برای تولید:

```bash
npm run build
```

4. پیش‌نمایش نسخه تولید:

```bash
npm run preview
```

## تنظیمات API

URL پایه API در فایل `src/store/auth.ts` قابل تنظیم است:

```typescript
const API_BASE_URL = "http://localhost:8080";
```

## صفحات

### صفحه ورود (`/login`)

- فرم ورود با اعتبارسنجی
- پیام‌های خطای کاربرپسند
- لینک به صفحه ثبت‌نام

### صفحه ثبت‌نام (`/register`)

- فرم ثبت‌نام با انتخاب انواع فایل مجاز
- اعتبارسنجی رمز عبور
- پیام موفقیت و هدایت خودکار

### داشبورد (`/`)

- نمایش اطلاعات کاربر
- لیست انواع فایل‌های مجاز
- کارت‌های ویژگی‌ها
- دسترسی سریع به آپلود فایل

### صفحه آپلود (`/upload`)

- آپلود با drag & drop
- نوار پیشرفت آپلود
- اعتبارسنجی نوع و حجم فایل
- پیام‌های موفقیت و خطا

## تم‌بندی

تم به صورت خودکار بر اساس تنظیمات سیستم کاربر تشخیص داده می‌شود و قابلیت تغییر دستی دارد:

- **حالت روشن**: برای روز
- **حالت تاریک**: برای شب
- **تغییر دستی**: با کلیک روی دکمه تم در نوار بالا

تم انتخابی در `localStorage` ذخیره می‌شود.

## تکنولوژی‌های استفاده شده

- **Vue 3**: فریمورک جاوااسکریپت
- **TypeScript**: برای type safety
- **Vue Router**: مسیریابی
- **Tailwind CSS**: استایل‌دهی
- **Vite**: ابزار ساخت
- **Vazirmatn**: فونت فارسی

## مدیریت وضعیت

از Composition API و Reactive state برای مدیریت وضعیت استفاده شده:

- **auth.ts**: مدیریت احراز هویت و اطلاعات کاربر
- **theme.ts**: مدیریت تم روشن/تاریک
